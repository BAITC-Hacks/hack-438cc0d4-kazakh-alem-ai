# AI Sana Challenge Hub

HackAlem AI хакатонына арналған KAZAKH ALEM AI командасының жобасы.

> Қазіргі нұсқада үш тілдік интерфейс, OpenAI арқылы талдау және Task Card жасау қосылған. API кілті жоқ немесе OpenAI қолжетімсіз болса, резервтік режим жұмыс істейді. Рейтинг әзірге тұрақты демо мәні; жариялау, каталог және команда ұсыныстары қосылмаған.

## 1. Жоба туралы

AI Sana Challenge Hub бизнес өкілінің қысқа не толық емес тапсырмасын студенттік командаға түсінікті, өңделетін карточкаға айналдыруға көмектеседі.

Қазір жұмыс істейтін ағын:

```text
Бизнес сипаттамасы + сала + тіл
→ POST /api/analyze
→ OpenAI талдауы немесе fallback
→ 3–4 нақтылаушы сұрақ
→ Барлық сұраққа жауап
→ POST /api/task-card
→ Өңделетін Task Card
→ 65/100 демо рейтинг + бос өрістер
→ Осы бетте растау
```

Жобаның көздеген толық ағыны `Business description → AI Agent → Task Card → Rating → Publish → Catalog → Team Proposal → Accept / Reject`. Соңғы жариялау және ұсыныс кезеңдері осы нұсқада іске асырылмаған.

## 2. Қандай мәселені шешеді

Қысқа бизнес тапсырмасында кім үшін шешім жасалатыны, қандай деректер бар екені, қандай нәтиже күтілетіні, табыс қалай өлшенетіні және шектеулер жиі көрсетілмейді. Агент сұрақтармен осы ақпаратты нақтылауға көмектеседі. Бизнес өкілі дайын карточканы тексеріп, түзете алады.

## 3. AI Agent

Негізгі модуль — [src/aiAgent.js](src/aiAgent.js).

- `analyzeTask(description, industry, language)` сипаттаманы талдап, `summary`, `missingFields`, 3–4 сұрақ және әр сұраққа сәйкес `questionFields` қайтарады.
- `createTaskCard(description, answers, industry, language)` жауаптардан құрылымдалған карточка жасайды.
- OpenAI тек backend-тен шақырылады. Frontend API кілтін алмайды.
- Әдепкі модель — `gpt-4o-mini`; оны `OPENAI_MODEL` арқылы өзгертуге болады. Таңдалған модель қолданылған Chat Completions және JSON Schema параметрлерін қолдауы керек.
- Жауап форматы `json_schema` және `strict: true` арқылы беріледі; код қосымша сұрақ санын, қайталануды, өрістер мен мәтін ұзындығын тексереді.
- Модельге берілмеген факт, мерзім, бюджет, технология немесе байланыс дерегін ойдан қоспау, белгісіз өрісті бос қалдыру нұсқауы беріледі. Пайдаланушы нәтижені тексеруі керек.
- API сұрауына 20 секундтық timeout қойылған; автоматты retry өшірілген. Қате, бас тарту, аяқталмаған не жарамсыз жауап болса fallback іске қосылады.
- `mode: "ai"` немесе `mode: "fallback"` қайтарылады; резервтік режимде `fallbackReason` себебі беріледі.

`improvement tips`, AI арқылы рейтинг есептеу және команданы автоматты таңдау жоқ.

**Үш тіл:** `kk` — қазақша, `ru` — орысша, `en` — ағылшынша. Тілді жоғарғы мәзірден таңдауға болады. Интерфейс, тексеру хабарлары, бос өрістер және fallback сұрақтар бірден ауысады. Жаңа AI сұрауы таңдалған тілде жасалады. Бұрынғы AI мәтіні мен енгізілген жауаптар автоматты аударылмайды; жаңа тілде сұрақтар алу үшін қайта талдау қажет. Тіл таңдауы ғана `localStorage` ішінде сақталады.

## 4. Task Card

Барлық 3–4 сұраққа бос емес жауап берілгенде ғана карточка жасалады. Тек бос орын енгізу жауап болып саналмайды.

| Өріс | Мазмұны |
| --- | --- |
| `title` | Тапсырма атауы |
| `context` | Контекст |
| `need` | Бизнес қажеттілігі |
| `users` | Қолданушылар |
| `data` | Қолжетімді деректер |
| `constraints` | Шектеулер |
| `expectedResult` | Күтілетін нәтиже |
| `successCriteria` | Табыс критерийлері |
| `contact` | Байланыс ақпараты |
| `interactionFormat` | Өзара әрекеттесу форматы |

Барлық 10 өріс өңделеді. API карточкасындағы `industry` мәні бастапқы формадағы саладан алынады; оны модель өзгерте алмайды.

Fallback сипаттаманы `context` өрісіне, алғашқы 100 таңбасын `title` өрісіне және жауаптарды тиісті өрістерге көшіреді. Өріске байланыстырылмаған жауап контекстке қосылады. Берілмеген мәліметтер бос қалады.

Қайта сақтағанда өзгерген жауаптарға сәйкес өрістер жаңарады; басқа қолмен өңделген өрістер сақталады. Бастапқы сипаттама не сала өзгерсе, қайта талдау қажет. Тілді ауыстыру енгізілген жауаптар мен карточка мәндерін өшірмейді.

**«Карточканы растау» серверге сақтамайды және жарияламайды.** Өңдегеннен кейін қайта растау қажет. Бетті жаңартқанда тапсырма, жауаптар және карточка жоғалады.

## 5. Рейтинг жүйесі

Рейтинг — әзірге демо:

- Карточкаға дейін: `0/100`.
- Карточка жасалған соң: тұрақты `65/100`.
- Деңгей: «Жұмысқа жарамды» / «Можно брать в работу» / `Workable`.
- Progress bar баллды көрсетеді.
- Бос өрістер тізімі карточканы өңдегенде жаңарады.

`public/app.js` ішіндегі формула:

```js
const score = cardCreated ? 65 : 0;
```

`src/rating.js` ішіндегі `calculateRating(task)` әлі `0` қайтарады және API-ге қосылмаған. Салмақталған 100 балдық формула, `draft/ready/priority` шектері және рейтингті серверде қайта есептеу жоқ. Барлық өріс толса да, интерфейстегі балл 65 болып қалады.

## 6. Каталог

Жариялау, каталог, рейтинг бойынша сұрыптау және сала/дайындық сүзгілері жоқ. `data/tasks.json` бос. `GET /api/tasks` іске асырылмаған; төмен рейтингті тапсырмаларды көрсету немесе жасыру ережесі әзірге жоқ.

## 7. Команда ұсыныстары

Команда таңдау, идея/жоспар/мерзім/прототип сілтемесін жіберу және Accept / Reject әрекеттері қосылмаған. `teams.json` мен `proposals.json` болашақ деректерге арналған бос файлдар. AI жеңімпазды таңдамайды.

## 10. Орнату

```bash
git clone https://github.com/BAITC-Hacks/hack-438cc0d4-kazakh-alem-ai.git
cd hack-438cc0d4-kazakh-alem-ai
git switch arsen-frontend
npm install
```

`.env.example` файлын `.env` атымен көшіріңіз. Бұрыннан бар `.env` файлын алмастырмаңыз. OpenAI қолдану үшін жеке кілтіңізді осы файлға енгізіңіз:

```dotenv
OPENAI_API_KEY=
PORT=3000
OPENAI_MODEL=gpt-4o-mini
HOST=127.0.0.1
```

Кілтсіз қалдырсаңыз, fallback іске қосылады. Кілт кодқа, браузерге, README-ге немесе Git-ке енгізілмейді. Кілт жасаудың ресми нұсқаулығы: [OpenAI Quickstart](https://developers.openai.com/api/docs/quickstart).

```bash
npm start
```

Содан кейін [http://localhost:3000](http://localhost:3000) ашыңыз. `public/index.html` файлын тікелей ашу API-ді қоспайды: бұл нұсқада сервер арқылы кіру қажет.

Windows PowerShell `npm.ps1` execution policy қатесін көрсетсе:

```powershell
npm.cmd install
npm.cmd start
```

Балама іске қосу: `node server.js`. `.env` өзгергеннен кейін серверді `Ctrl+C` арқылы тоқтатып, қайта іске қосыңыз. Порт бос болмаса, басқа порт таңдаңыз немесе бұрынғы серверді тоқтатыңыз.

## 11. OpenAI API болмаса

Кілт жоқ болса `mode: "fallback"`, `fallbackReason: "missing_key"` қайтады. OpenAI timeout, қате, refusal немесе жарамсыз JSON қайтарса, себеп `api_unavailable` болады. UI нақты режимді көрсетеді.

Fallback әр тілде мына мағынадағы үш сұрақты береді:

1. Шешімді нақты кімдер қолданады?
2. Қандай деректер немесе материалдар қолжетімді?
3. Команда жұмысының соңында қандай нәтиже күтіледі?

Сипаттамада `Қолданушылар: ...; Деректер: ...; Күтілетін нәтиже: ...` түріндегі нақты мәндер танылса, олар missing fields тізімінен алынады. Орысша және ағылшынша өріс атаулары да танылады. Бұл ережелік талдау еркін мәтіннің мағынасын толық түсінбейді.

Fallback жауаптарды карточкаға көшіреді; қолданушының жауаптары жоғалмайды. Сервердің өзі қолжетімсіз болса, интерфейс байланыс қатесін көрсетеді.

## 12. Қалай тексеруге болады

### Браузерде

1. `npm start` орындап, `http://localhost:3000` ашыңыз.
2. Қазақша, Русский және English арасында ауысыңыз.
3. Бос форманы жіберіп, validation хабарламаларын тексеріңіз.
4. «Білім беру» саласын таңдаңыз, «Студенттерге арналған оқу платформасы керек.» деп енгізіңіз.
5. «AI арқылы талдау» басыңыз. Кілтсіз — 3 стандартты сұрақ; жарамды AI жауабында — 3–4 сұрақ.
6. Бір жауапты бос қалдырып сақтаңыз: карточка жасалмауы керек.
7. Барлық жауапты толтырып сақтаңыз: Task Card-та жауаптар көрінуі керек.
8. Тілді ауыстырыңыз: өріс атаулары аударылады, енгізілген мәтін сақталады.
9. Бос карточка өрісін толтырыңыз: ол missing fields тізімінен жоғалады, рейтинг 65 болып қалады.
10. Карточканы растаңыз, сосын өңдеңіз: қайта растау сұралады.
11. Бетті жаңартыңыз: тіл таңдауы сақталады, тапсырма деректері тазарады.

### API

| Маршрут | Қызметі |
| --- | --- |
| `GET /api/health` | `{ "status": "ok" }` |
| `GET /api/config` | `{ "aiConfigured": true/false }`; тек кілттің конфигурацияда барын көрсетеді, жарамдылығын тексермейді |
| `POST /api/analyze` | `description`, `industry`, қосымша `language` → сұрақтар, өрістер, summary, режим |
| `POST /api/task-card` | Сол мәліметтер және `answers` → карточка және режим |

PowerShell мысалы:

```powershell
Invoke-RestMethod 'http://localhost:3000/api/health'
$payload = @{
  description = 'Студенттерге арналған оқу платформасы керек.'
  industry = 'education'
  language = 'kk'
} | ConvertTo-Json
Invoke-RestMethod -Uri 'http://localhost:3000/api/analyze' `
  -Method Post -ContentType 'application/json; charset=utf-8' `
  -Body ([System.Text.Encoding]::UTF8.GetBytes($payload)) | ConvertTo-Json -Depth 6
```

`answers` — 3–4 объектіден тұратын массив: `{ "question": "...", "field": "users", "answer": "..." }`. `field` мәні талдау жауабындағы `questionFields` массивінен алынады. Барлық жауап бос емес, сұрақтар қайталанбайтын болуы керек. Сипаттама мен әр жауап ең көбі 5000 таңба. Қате енгізу — `400`; жарамсыз JSON — `400`; 128 KB-тан үлкен body — `413`.

### Автоматты тексеру

```bash
npm test
```

Тесттер сыртқы OpenAI-ге сұрау жібермейді: кілтсіз режим және mock клиент қолданылады. Олар үш тілдегі жауаптарды, fallback, карточкаға көшіруді, AI JSON тексерістерін, validation және аударма сөздігін тексереді. Нақты OpenAI сұрауын тексеру үшін өз кілтіңізбен талдау жасап, интерфейсте AI режимі көрсетілгенін тексеріңіз.

## 14. Шектеулер

- Рейтинг тұрақты демо мәні; нақты бағалау формуласы жоқ.
- Карточканы серверде сақтау, жариялау, каталог және ұсыныстар жоқ.
- Тіркелу, рөлдер, production authentication және rate limiting жоқ; сервер әдепкіде тек жергілікті `127.0.0.1` интерфейсінде тыңдайды.
- Realtime чат, хабарландырулар және дерекқор жоқ.
- Бетті жаңартқанда бизнес деректері жоғалады; тек тіл таңдауы сақталады.
- AI мәтіні фактілерді қолмен тексеруді қажет етеді. UI-де тілді ауыстыру бұрынғы AI мәтінін автоматты аудармайды.
- Қалыпты AI режимі жарамды OpenAI кілтіне және API қолжетімділігіне тәуелді.
